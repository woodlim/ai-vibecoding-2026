### 자동매매 일일 사용금액

화면의 **자동매매 내역**에서 체결 시각(한국 시간), 종목명·코드, 매수/매도, 체결 수량, 체결 단가, 거래금액, 상태를 확인할 수 있습니다. 최신 거래가 위에 표시되며 5초마다 갱신됩니다. 거래금액은 체결 단가 × 체결 수량이며, 수동 주문은 이 목록에서 제외됩니다.

- 수동 가상주문 입력과 추천 카드의 수동 매수 버튼은 제거했습니다. `자동매매 시작`으로 PAPER 자동매매를 실행합니다.
- 추천 TOP 5는 참고용으로만 표시합니다. 자동매매 시작 시 추천 목록과 무관하게 토스의 국내 시장 전체 거래량 상위 100개와 당일 상승률 상위 100개를 비교해 후보를 찾습니다.
- 매수 후보는 두 랭킹에 모두 포함되고 당일 상승률이 1% 이상인 종목입니다. 상승률과 거래량 순위를 점수화해 가장 높은 후보부터 판단합니다. 이는 외부 LLM/AI 예측이 아니라 규칙 기반 모멘텀 스크리너입니다.
- 보유 종목이 상승·거래량 조건에서 이탈하거나 매입 평균가 대비 3% 하락하면 PAPER 매도합니다. 중지 버튼은 반복 매매만 멈추며 보유 주식을 강제로 매도하지 않습니다.
- 계좌 요약에는 가용계좌 금액, 하루 추천 사용금액(40%), 평가손익, 수익률을 표시합니다.
- 하루 첫 자동매매 시작 시 가용 현금의 40%를 그날의 누적 매수 한도로 확정합니다. 시작 전 화면의 금액은 현재 현금 기준 예상 한도입니다.
- 매수 신호가 나오면 잔여 한도와 가용 현금 안에서 살 수 있는 최대 정수 수량을 매수합니다. 1주 가격이 한도를 넘으면 매수를 건너뜁니다.
- 같은 날 중지·재시작하거나 종목을 바꿔도 사용액을 유지합니다. 매도대금으로 하루 매수 한도가 늘어나지 않습니다.
- 한국 시간 자정 이후 첫 자동매매 처리 시 당시 가용 현금으로 새 한도를 계산합니다. 추천 카드의 최대 수량은 잔여 한도 기준입니다.
- 이 한도는 PAPER 자동매매에 적용하며, 수동 주문은 별도입니다. 현재 계좌와 일일 한도는 메모리에 저장되므로 서버를 재시작하면 초기화됩니다.

후보 스캐너는 토스 랭킹 API가 시장 전체 기준으로 반환하는 거래량·등락률 랭킹(각 최대 100개)을 사용합니다. 따라서 모든 상장 종목의 호가/차트를 매번 개별 호출하는 구조가 아니며, 토스 랭킹에 잡히지 않은 종목은 해당 주기에 후보에서 제외될 수 있습니다. 토스 공식 문서에는 테마 분류 랭킹이 없어 테마는 사용하지 않습니다.

서버 실행: `python -m app` (접속 주소: `http://127.0.0.1:8000`). 서버 코드 변경은 재시작 후 적용됩니다.

### 주식 자동매매 파이썬 프로그램 분석

- `__init__.py` - 일반적으로 파일만 생성. 소스코드 X , 프로젝트 폴더가 pip로 설치할 수 있는 패키지화
- `__main__.py` - 파이썬으로 실행될때 가장 먼저 실행되는 메인 함수 파일
- `__pycahe__` - 미리 만들어놓은 파이썬 실행 파일(캐시)
- tests - 소스코드 테스트 실행을 위한 폴더
- .env.example - 환경 설정 예제파일 .example을 지우고 사용
    .env 는 깃허브에 업로드 방지위해 .gitignore에 제외파일로 등록
- requriements.txt - 파이썬 개발환경 패키지 설치리스트 파일
    - `pip install -r requirements.txt` 로 설치
