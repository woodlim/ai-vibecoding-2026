# ai-vibecoding-2026

### PAPER 매매 수수료

- 가상 체결은 매수·매도 수수료를 현금, 보유주식 취득 비용, 실현손익과 수익률에 반영합니다. 주문별 수수료는 원 미만을 버리고, 매수 정산금액은 거래금액+수수료, 매도 정산금액은 거래금액−수수료입니다. 자동매수 예산과 수량도 수수료를 포함합니다.
- 서버 시작 시 토스 `GET /api/v1/commissions`에서 현재 적용 중인 국내주식 계좌 요율을 조회합니다. `.env`의 `TOSS_ACCOUNT_SEQ`가 없으면 `GET /api/v1/accounts`의 계좌가 하나일 때만 선택합니다. 조회 실패나 적용 기간 만료 시 KRX 기본 요율 **0.015%**를 사용하고 화면에 미확인 상태를 표시합니다. 계좌 혜택 변경 시 서버를 재시작해 다시 조회하세요.
- 가상 체결에는 거래소 정보가 없어 NXT 0.014%를 자동 구분하지 않습니다. 매도 세금·슬리피지는 이번 계산에 포함하지 않습니다. 보유주식 평가는 체결된 매수 수수료를 반영하며 향후 매도 수수료는 미리 차감하지 않습니다. 실제 토스 주문은 발생하지 않습니다.
- 기존 버전 1 계좌는 KRX 기본 요율로 과거 거래를 **추정 재계산**합니다. 현재 계좌 요율을 과거 혜택으로 소급하지 않습니다. 원본은 `data/paper-state.pre-commissions.json`에 보존하며 버전 2로 저장되어 재시작 시 중복 차감하지 않습니다. 현금 부족 또는 체결 내역과 보유 수량 불일치 시 원본을 수정하지 않고 시작을 중단합니다.
- 요율 근거: [토스증권 OpenAPI 안내](https://home.tossinvest.com/ko/open-api), [공식 OpenAPI 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json). 원 미만 절사 근거: [토스증권 미수거래 설명서](https://home-files.tossinvest.com/files/notice/08c1ab8d-7a95-43a6-8b27-3e75ec183e2f.pdf). 확인일: 2026-10-02.

### 자동매매 일일 사용금액

화면의 **매매 내역**에서는 최근 10건을 최신순으로 표시합니다. 아래 **매매내역 보기** 버튼을 누르면 `/trade-history` 페이지에서 전체 내역을 볼 수 있습니다. 두 화면 모두 체결 시각(한국 시간), 종목명·코드, 매수/매도, 체결 수량, 체결 단가, 거래금액, 수수료, 정산금액, 매도 실현손익, 상태(자동/수동)를 표시하고 30초마다 갱신됩니다. 실현손익은 매도 정산금액에서 매수 평균원가와 해당 수량에 배분된 매수 수수료를 뺀 금액이며 수익률도 함께 표시됩니다.

- 보유 포지션의 상태 옆 **전량 매도** 버튼으로 직접 PAPER 매도할 수 있습니다. 종목과 수량 확인 후 최신 조회 시세로 가상 체결하며, 실제 계좌 주문은 발생하지 않습니다. 자동매매 중지 상태에서도 사용할 수 있습니다.
- 최신 시세 조회 실패 시 매도하지 않습니다. 확인 후 보유 수량이 변했거나 이미 자동매도된 경우 요청을 거절하며, 새로고침 후 다시 확인해야 합니다.
- 직접 매도한 종목은 당일 자동 재매수에서 제외합니다. 수동 매도로 회수한 당일 자동매수 원금은 재사용할 수 있습니다. 수익은 한도에 더하지 않고, 손실 매도 시 회수한 금액까지만 재사용합니다. 누적 매수액은 통계로 유지하고 `순사용 = 누적 자동매수액 - 수동 매도 회수원금`으로 매수 여유를 판단합니다.
- 수동 전량 매도로 생긴 빈자리는 최대 5종목까지 새 적격 종목으로 보충합니다. 자동매매를 시작하거나 실행 중 `빈자리 N종목 채우기`를 누르면 바로 후보를 확인합니다. 실행 중에는 다음 조회 주기에도 자동 보충합니다. 이 보충만 15분 대기를 건너뛰고, 기존 보유 종목의 일반 추가 매수 간격은 유지합니다. 후보 부족·현금 부족·종목별 한도에 걸리면 빈자리가 남을 수 있습니다.
- 계좌 요약의 `누적 실현손익`은 체결이 끝난 매도 주문의 손익 합계이고, `평가손익`은 현재 보유주식의 평가손익과 실현손익을 합친 전체 손익입니다. 분할 매수 후 매도하면 해당 시점의 평균 매수가로 계산합니다.
- 수동 전량 매도 API: `POST /api/v1/positions/{symbol}/sell` (`quantity`: 확인한 보유 수량, `client_order_id`: 중복 방지 요청 ID).

- 수동 가상주문 입력과 추천 카드의 수동 매수 버튼은 제거했습니다. `자동매매 시작`으로 PAPER 자동매매를 실행합니다.
- 추천 TOP 5는 참고용으로만 표시합니다. 자동매매 시작 시 추천 목록과 무관하게 토스의 국내 시장 전체 거래량 상위 100개와 당일 상승률 상위 100개를 비교해 후보를 찾습니다.
- 매수 후보는 두 랭킹에 모두 포함되고 당일 상승률이 1% 이상인 종목입니다. 상승률과 거래량 순위를 점수화해 가장 높은 후보부터 판단합니다. 이는 외부 LLM/AI 예측이 아니라 규칙 기반 모멘텀 스크리너입니다.
- 하루 매수 목표는 설정 한도의 87.5%입니다. 시작 시 가용 현금 1,000만 원·한도 40%라면 한도 400만 원, 목표 350만 원입니다. 50% 설정 시 목표는 가용 현금의 43.75%로 비례해서 바뀝니다. 목표와 한도는 그날 처음 자동매매를 시작한 시점의 가용 현금을 기준으로 계산합니다.
- 매수는 최대 5종목에 분산하며, 한 회차에 목표의 최대 25%씩 최소 15분 간격으로 진행합니다. 목표 350만 원이면 회차 합계 최대 87만 5천 원입니다. 종목 가격과 남은 여유에 맞춰 배분하고 정수 수량 때문에 남은 금액은 다른 적격 종목에 재배분합니다.
- 기본 4회 이후에도 순사용 금액이 목표에 미달하면 같은 간격과 회차 한도를 지켜 추가 분할 매수를 시도합니다. 종목당 누적 매수액과 기존 보유 원금은 설정 한도의 최대 20%로 제한합니다. 조건에 맞는 종목이 부족하거나 남은 금액으로 1주를 살 수 없으면 목표에 미달할 수 있습니다. 수동 매도 보충도 회차 한도를 지키며, 전체 보유 원금이 목표를 넘도록 추가 매수하지 않습니다. 자동 매도는 재사용 한도를 복원하지 않습니다.
- 보유 종목이 평균 매수가 대비 -3% 이하이면 손절, +10% 이상이면 익절하여 전량 PAPER 매도합니다. 분할 매수 후에는 갱신된 평균 매수가를 기준으로 판단하며, 상승·거래량 조건 이탈 시에도 전량 매도합니다. 매도한 종목은 당일 자동 재매수하지 않습니다.
- 매도 조건은 모든 보유 종목에 대해 자동매매 실행 중 약 60초 간격으로 확인합니다. 일부 종목의 시세 조회에 실패하면 해당 종목의 자동매도와 신규 매수는 보류하되, 정상 조회된 다른 종목의 매도는 판단합니다. 조회 가격으로 가상 체결하므로 정확히 -3%/+10% 가격에 체결된다는 보장은 없습니다. 중지 버튼은 반복 매매만 멈추며 보유 주식을 강제로 매도하지 않습니다.
- 계좌 요약에는 가용계좌 금액, 하루 추천 사용금액(40%), 평가손익, 수익률을 표시합니다.
- 기본 비율은 40%이며, 계좌 요약에서 0~100%로 변경할 수 있습니다. 변경한 비율은 오늘 누적 매수 한도에 즉시 반영되며, 이미 사용한 금액보다 한도가 낮아지면 잔여 한도는 0원이 됩니다.
- 첫 자동매매 시작 시 현재 가용 현금과 설정 비율로 그날의 매수 한도를 계산합니다. 시작 전 화면의 금액은 현재 현금 기준 예상 한도입니다.
- 매수 신호가 나오면 해당 분할 몫·잔여 한도·가용 현금 안에서 살 수 있는 최대 정수 수량을 매수합니다. 한 회차 예산으로 1주도 살 수 없으면 매수를 건너뜁니다.
- 같은 날 중지·재시작해도 누적 매수액·수동 매도 회수원금·남은 보충 자리를 유지합니다. 회수원금과 보충 자리는 체결 내역으로 계산하므로 서버 재시작이나 중복 요청으로 중복 반영되지 않습니다. 날짜가 바뀌면 새 거래일의 체결 내역을 기준으로 계산합니다.
- 한국 시간 자정 이후 첫 자동매매 처리 시 당시 가용 현금으로 새 한도를 계산합니다. 추천 카드의 최대 수량은 잔여 한도 기준입니다.
- 이 한도는 PAPER 자동매매에 적용하며, 수동 주문은 별도입니다. 잔고·보유주식·주문·일일 사용액·분할 횟수·재매수 제외 종목·설정 비율은 `data/paper-state.json`에 자동 저장되어 재시작 후 복원됩니다. 파일은 Git에서 제외됩니다. 저장 실패 시 해당 주문/변경을 취소하며 손상된 파일을 발견하면 계좌를 초기화하지 않고 서버 시작을 중단합니다.
- 새 계좌의 기본 비율은 `.env`의 `AUTO_BUY_BUDGET_PERCENT`입니다. 저장된 계좌가 있으면 저장된 비율을 우선합니다. 재시작 후 자동매매는 안전을 위해 중지 상태로 복원되므로 `자동매매 시작`을 눌러 재개합니다. 한 계좌 파일에는 서버 프로세스를 하나만 실행하세요(`--workers` 증설 금지).

후보 스캐너는 토스 랭킹 API가 시장 전체 기준으로 반환하는 거래량·등락률 랭킹(각 최대 100개)을 사용합니다. 따라서 모든 상장 종목의 호가/차트를 매번 개별 호출하는 구조가 아니며, 토스 랭킹에 잡히지 않은 종목은 해당 주기에 후보에서 제외될 수 있습니다. 토스 공식 문서에는 테마 분류 랭킹이 없어 테마는 사용하지 않습니다.

서버 실행: `python -m app` (접속 주소: `http://127.0.0.1:8000`). 서버 코드 변경은 재시작 후 적용됩니다.

- `__init__.py` - 일반적으로 파일만 생성. 소스코드 X , 프로젝트 폴더가 pip로 설치할 수 있는 패키지화
